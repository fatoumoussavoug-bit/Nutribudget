# NutriBudget 🥗💰

> **Mangez sainement, sans vous ruiner.**  
> Des plans alimentaires adaptés à votre portefeuille, avec des produits locaux accessibles.

## 📖 À propos

**NutriBudget** est une plateforme web conçue pour aider à adopter une alimentation équilibrée et accessible à petit prix, notamment avec des produits locaux du marché (Dakar).

### ✨ Fonctionnalités
- **Landing Page moderne et responsive** : Présentation du service, fonctionnement étape par étape, tarifs et témoignages.
- **Simulateur de budget** interactif.
- **Modal de contact & formulaire** intégrés.
- **Design soigné** : Typographie Google Fonts (Inter), palette de couleurs harmonieuse, micro-animations.

## 🚀 Technologies utilisées

- **HTML5** (Structure sémantique, SEO)
- **CSS3** (Variables CSS, Flexbox, Grid, Responsive Design)
- **JavaScript (Vanilla)** (Interactivité, modal, navigation)

## 💻 Installation et utilisation locale

1. Clonez ce dépôt :
   ```bash
   git clone https://github.com/fatoumoussavoug-bit/Nutribudget.git
   ```
2. Ouvrez le dossier dans votre navigateur ou lancez un serveur local :
   ```bash
   cd Nutribudget
   # Ouvrez directement index.html ou utilisez une extension Live Server
   ```
